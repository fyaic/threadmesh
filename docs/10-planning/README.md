# Project planning

This directory is the canonical home for current project status and execution
planning. The roadmap describes milestone outcomes; these documents describe
where the repository is now and what work should happen next.

- [Project status](project-status.md) — evidence-backed snapshot of shipped,
  experimental, blocked, and unstarted work.
- [Mainline plan](mainline-plan.md) — ordered workstream from the current
  prototype to a reviewable protocol and complete local coordinator.

Status statements are dated and should be updated whenever a pull request
materially changes a milestone exit criterion. GitHub milestones and issues are
the source of truth for acceptance and closure.
